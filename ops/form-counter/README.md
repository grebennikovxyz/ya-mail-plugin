# Счётчик открытий формы Ya-Ma

Каждая загрузка формы на GitHub Pages вызывает один GET `/ya-ma/open.gif`. Перезагрузка страницы учитывается ещё раз. Блокировщик может пропустить запрос. Клиент передаёт фиксированный путь и Origin сайта. Фрагмент ссылки, адрес ящика, код подключения и пароль в запрос не входят.

Сервису достаточно Python 3 и SQLite из стандартной библиотеки. От имени владельца базы создайте закрытый каталог и запустите приёмник за существующим HTTPS-прокси.

```sh
install -d -m 700 "$HOME/.local/state/ya-ma-counter"
python3 counter.py serve "$HOME/.local/state/ya-ma-counter/count.sqlite3" --port 8768
```

Приёмник слушает только loopback. На всех прокси для этого маршрута отключите access logs, error logs с данными запросов, трассировку и кэш. Передавайте приложению только фиксированный путь без переписывания и заголовок Origin. Разрешите публичный GET только на точный путь без query. Прокси должен сохранять Cache-Control и Access-Control-Allow-Origin из ответа. Проверяйте состояние процесса отдельно, чтобы мониторинг не увеличивал итог.

Владелец читает единственное число в своей закрытой SSH-сессии.

```sh
python3 counter.py total "$HOME/.local/state/ya-ma-counter/count.sqlite3"
```

Ответ публичного маршрута всегда содержит одно и то же изображение при успешном учёте. База хранит одно целое значение и не содержит журнала посещений. Доступ на уровне администратора хоста позволяет прочитать базу. Если счётчик недоступен, подключение почтового ящика по-прежнему работает.
