# Яндекс Почта для Codex

Неофициальный плагин для личной почты и доменных ящиков Яндекс 360. Агент может разобрать переписку, найти вложение, поставить метки, подготовить ответ или проверить новые письма по расписанию. У каждого подключённого ящика свой режим доступа. Потребуются Git, [uv](https://docs.astral.sh/uv/getting-started/installation/) и клиент с поддержкой локального MCP.

## Установка

Выполните в терминале пользователя, под которым работает Codex.

```sh
uv tool install --python 3.13 git+https://github.com/grebennikovxyz/ya-mail-plugin.git@main
uv tool update-shell
```

Откройте новый терминал и выполните команды установки каталога и плагина.

```sh
codex plugin marketplace add https://github.com/grebennikovxyz/ya-mail-plugin.git --ref main
codex plugin add yandex-mail@grebennikov-mail
ya-mail connect
```

В клиенте с ручной настройкой MCP выберите транспорт **stdio**, команду `ya-mail` и аргумент `serve`. В клиенте с импортом ZIP можно импортировать архив плагина после установки команды `ya-mail`. Начните новый чат и попросите «Покажи подключённые ящики».

Для Windows x64 доступна автономная сборка. Скачайте архив с окончанием `-windows-x64.zip`, распакуйте и запустите `connect.cmd`. В архив входят Python и библиотеки. Импортируйте ZIP в поддерживающий это клиент. Для ручного добавления MCP укажите полный путь к `runtime/python.exe` из распакованного архива и аргументы `-I -B -m ya_mail.cli serve`. Для официального сервера используйте `connect-360.cmd` и последний аргумент `serve-360`. [Сборки для скачивания](https://github.com/grebennikovxyz/ya-mail-plugin/releases)

## Мастер подключения

1. Нажмите **Открыть настройки Почты**. Выберите нужный ящик, включите IMAP и способ входа «Пароли приложений и OAuth-токены». Сохраните настройки. [Почтовые программы](https://mail.yandex.ru/#setup/client)
2. Нажмите **Открыть Яндекс ID**. У того же аккаунта выберите тип приложения **Почта**, введите название, например «Ya Mail для Codex», и нажмите **Далее**. Скопируйте сгенерированный пароль. Яндекс показывает его один раз. Он продолжает работать до отзыва, в том числе во время запусков по расписанию. [Пароли приложений](https://id.yandex.ru/security/app-passwords)
3. Введите полный адрес ящика и вставьте пароль в скрытое поле мастера. Выберите **Только чтение**, **Чтение, метки, папки и черновики** или **Также разрешить отправку писем**. Мастер проверит IMAP, а для режима отправки также выполнит вход по SMTP. После успешной проверки пароль сохранится в Windows Credential Manager, macOS Keychain или Linux Secret Service. Эти режимы ограничивают инструменты плагина. Права самого пароля задаёт Яндекс.
4. Команда `ya-mail status` покажет сохранённый ящик и его режим. Чтобы проверить соединение с Яндексом, выполните `ya-mail check адрес@домен`. Команда покажет число папок и непрочитанных писем. Попросите в чате «Покажи пять последних писем в папке INBOX ящика …». Повторите мастер для дополнительного адреса или смены режима.

На Windows из распакованного исходного проекта мастер также открывается файлом `connect.cmd`. Для терминала без графической оболочки есть `ya-mail connect --terminal`. Если вход отклонён, проверьте тип пароля, адрес, настройки IMAP и ограничения администратора домена. [Справка Яндекса](https://yandex.ru/support/yandex-360/customers/mail/ru/mail-clients/others)

## Что можно поручить

| Задача | Возможности |
| --- | --- |
| Найти письма | По всем доступным папкам или по выбранной папке. Фильтры по отправителю, получателю To, теме, тексту, Message-ID, датам получения, прочитанности, звёздочке и метке. Страницы внутри папки идут от новых UID к старым. |
| Разобрать переписку | Пакетное чтение, просмотр цепочки по заголовкам References и In-Reply-To, получение продолжения длинного текста. Чтение сохраняет статус непрочитанного письма. Для старой переписки без связывающих заголовков используйте поиск по собеседнику и теме. |
| Получить вложение | Имена, MIME-типы и содержимое по частям. Для полного разбора письма с вложениями действует предел 32 МиБ. |
| Организовать ящик | Папки и счётчики, создание папок, пакетное изменение меток, прочитанности и звёздочек, перенос в архив, спам и корзину. Системные папки определяются по данным сервера. Если нужная роль отсутствует, можно выбрать существующую папку по имени. |
| Подготовить и отправить | Серверные черновики, ответы с сохранением связи по Message-ID, пересылка оригинала как EML, To/Cc/Bcc и файловые вложения. Отправка доступна в режиме с SMTP. Ключ запроса защищает от повторной отправки при повторе вызова. После отправки сохранённого черновика его можно переместить в корзину. |
| Применить метки | В режиме пароля приложения плагин устанавливает IMAP keywords и проверяет флаги на сервере. Простые имена вроде `orders` передаются напрямую. Для пробелов и кириллицы используется обратимое кодирование. Отображение этих имён в других клиентах зависит от сервера. Для нативных меток веб-почты используйте подключение Яндекс 360 ниже. |

## Подключение нативных меток Яндекс 360

Плагин включает второй MCP-сервер `yandex-mail-360` для официальных инструментов Яндекса. Он позволяет выбрать метку веб-почты, найти помеченные письма, применить или снять метку, изменить черновик. Это отдельное подключение с OAuth к выбранному у Яндекса аккаунту. Для основного режима достаточно пароля приложения. Доступность официального сервиса зависит от аккаунта и тарифа. [Официальный MCP Яндекс 360](https://yandex.ru/dev/yandex-360/mcp/ru/mail) · [API Почты](https://yandex.ru/dev/yandex-360/mail/ru/)

Выполните `ya-mail connect-360` в интерактивном терминале. Мастер откроет страницу согласия Яндекса, предложит ввести полученный токен в скрытом поле, выбрать режим и проверит список доступных инструментов. Токен сохраняется в системном хранилище. После подключения начните новый чат. Попросите «Через Яндекс 360 найди письма с меткой Договоры». Для ручной настройки второго сервера используйте команду `ya-mail` и аргумент `serve-360`. Список действий предоставляет Яндекс. Идентификаторы сообщений своего IMAP-подключения и идентификаторы официального сервера используйте в соответствующем подключении.

## Запланированные задачи

В настольном ChatGPT с поддержкой локальных плагинов выберите выполнение на этом компьютере. В обычном чате подключите плагин, один раз выполните проверку, затем попросите в этом же чате повторять её в нужное время. Созданная задача появится в разделе **«Запланированное»**. Для запуска оставьте компьютер включённым, а приложение открытым. [Инструкция OpenAI по задачам с плагинами](https://developers.openai.com/training/walkthroughs/scheduled-tasks)

В **локальном Codex** создайте задачу по времени, включите этот плагин и укажите адрес ящика. Запустите первую проверку при настройке, чтобы зафиксировать начальную позицию. Компьютер и системное хранилище пользователя должны быть доступны во время запуска. Пример текста для ежедневной задачи:

> Проверяй входящие ящика orders@example.org. Вызови poll_new для INBOX с именем orders-morning. Прочитай новые письма о заказах, подготовь сводку с отправителями и темами. После обработки всех писем из пакета подтверди его через acknowledge_batch. Если есть продолжение, обработай и его. Сообщи о новых заказах.

Первый вызов начинает наблюдение с текущего конца папки. Чтобы начать с накопленной почты, задайте `include_existing=true` в первом вызове. У каждой комбинации «ящик, папка, имя задачи» своя позиция. Повтор после сбоя вернёт неподтверждённые письма. Для задач с внешними действиями учитывайте возможную повторную обработку. Если IMAP-сервер изменил UIDVALIDITY, плагин остановит чтение этой ленты и сообщит об этом.

Проверка по времени доступна исполнителю, который запускает локальный MCP. Облачная функция ChatGPT Scheduled зависит от доступных в рабочем пространстве приложений. В опубликованном перечне встроенных событий новой почты OpenAI указывает Gmail. Установка этого пакета сама по себе не добавляет Яндекс в список облачных событий. [Расписания ChatGPT](https://help.openai.com/en/articles/10291617-scheduled-tasks-in-chatgpt)

## Хранение данных и отключение

Основной сервер соединяется по TLS с `imap.yandex.ru:993` и `smtp.yandex.ru:465`. В каталоге приложения хранятся адреса подключений, названия меток, позиции расписаний и журнал защиты от повторной отправки с Message-ID и результатами SMTP по адресатам. Плагин обрабатывает содержимое писем и вложений в памяти. Данные, которые агент запросил, также обрабатываются клиентом согласно его настройкам. Плагин предназначен для личного локального исполнителя.

`ya-mail disconnect адрес@домен` удаляет пароль из локального хранилища и локальные данные этого ящика. Для полного отзыва удалите созданный пароль в Яндекс ID. Дополнительное подключение отключается командой `ya-mail disconnect-360`. Отозвать выданный ему токен можно в разделе «Доступы к данным» своего аккаунта. [Пароли приложений](https://id.yandex.ru/security/app-passwords) · [Доступы к данным](https://id.yandex.ru/profile/access)
