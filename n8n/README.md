# Яндекс Почта для n8n

Нода **Яндекс Почта (Ya-Ma)** использует каталог операций почтового шлюза Ya-Ma. В редакторе n8n выберите операцию. Для адреса ящика, имени папки, номера части вложения, размера страницы и других аргументов появятся соответствующие поля. Для составных значений, например списка писем или условий поиска, поля принимают JSON или выражение n8n.

## Установка в self-hosted n8n


Скачайте пакет `n8n-nodes-ya-ma-0.5.0.tgz` из артефактов сборки репозитория или соберите его командами ниже. В каталоге `~/.n8n/nodes` служебного пользователя n8n установите файл командой `npm install /полный/путь/n8n-nodes-ya-ma-0.5.0.tgz`. Перезапустите n8n и его workers, установив на каждом одинаковую версию. Для Docker используйте постоянный том каталога n8n. Поддерживается API нод n8n версии 1 и n8n-workflow 2.x.

1. Подключите ящик командой `ya-mail connect` на машине владельца почты, включите подходящий режим и запустите личный `ya-mail serve-http` за HTTPS-прокси. [Настройка шлюза](https://github.com/grebennikovxyz/ya-mail-plugin#readme)
2. Добавьте **Яндекс Почта (Ya-Ma)** в workflow. Создайте credential **Ya-Ma Gateway**, укажите полный HTTPS URL с путём `/mcp` и Bearer-ключ этого шлюза. Пароль приложения Яндекса остаётся в системном хранилище на машине шлюза.
3. Выполните **List Accounts**. Данные инструмента находятся в `$json.result`. Каждому входному элементу соответствует один выходной элемент. **Search Messages** принимает адрес, необязательное имя папки и фильтр, например `{"unread":true,"has_attachment":true}`.

## Новые письма по расписанию

Соедините **Schedule Trigger → Яндекс Почта / Poll New → обработка пакета → Яндекс Почта / Acknowledge Batch**. Для Poll New сохраните постоянные Account, Folder и Feed. Передайте полученный receipt последней ноде после успешной обработки *всего* пакета. Ветку подтверждения запускайте только при непустом receipt. При has_more повторите опрос. На первом запуске режим Include Existing определяет, начинать ли с накопленных писем. У каждого ящика и папки собственный receipt. При остановке workflow тот же пакет можно получить снова.

Для ответа передайте **Prepare Reply** исходный ref и текст, а затем, если нужна отправка, **Send Draft** с ref созданного черновика. Для **Send Email** сохраните устойчивый UUID для конкретного письма, чтобы повтор workflow использовал тот же Request ID. Снятие запрета на закрытую папку требует подтверждения владельца в интерактивном MCP-клиенте.

## Сборка

```sh
cd n8n
npm ci --ignore-scripts
npm test
npm pack
```

Каталог операций формируется из схем Ya-Ma командой `python n8n/scripts/export_catalog.py` из корня с установленным Python-пакетом. [Установка community nodes](https://docs.n8n.io/integrations/community-nodes/installation/manual-install/)
