Подключить Яндекс Почту

Откройте ссылку из личного чата с Ya-Ma.

Сайт не получает пароль приложения. Ваш браузер шифрует его открытым ключом из ссылки. Открывайте ссылку, которую только что запросили в своём личном чате с Ya-Ma.

Кто может прочитать пароль и как это проверить?

В тот же чат вы возвращаете зашифрованный код YM1. Закрытый ключ для него создаёт ваша установка Ya-Ma. Она расшифровывает код, проверяет пароль у Яндекса по защищённому соединению и сохраняет его в выбранном вами хранилище. Если OpenClaw работает на сервере, это хранилище находится на сервере OpenClaw.

Код подключения действует 10 минут с момента запроса и принимается один раз. Сам пароль приложения можно отозвать в Яндекс ID.

Откройте вкладку «Сеть» в инструментах браузера, введите вымышленное значение из латинских букв и нажмите «Получить код для чата». При шифровании сетевого запроса не будет. Исходный код формы · Расшифровка на вашей стороне

В настройках Почты включите IMAP. В Яндекс ID создайте пароль приложения типа «Почта» для этого ящика.

Браузер зашифрует пароль для вашей установки Ya-Ma. В личный чат отправьте только полученный код.
